# Copilot in PowerPoint: organization skills

Admins package skills with a `manifest.json` (manifestVersion 1.30, `agentSkills` array) and two icons, upload the zip in the Microsoft 365 admin center under **Agents > All agents > Add agent**, and target all users or specific users and groups.

Full steps, the package layout and the build commands: [org-deploy/README.md](../org-deploy/README.md).

Sources, read 2026-10-24: Microsoft Support, [Deploy organization skills for Copilot in PowerPoint](https://support.microsoft.com/en-us/powerpoint/copilot/deploy-organization-skills-for-copilot-in-powerpoint); [MC1463509](https://mc.merill.net/message/MC1463509) (Frontier, 28 Aug 2026); [MC1478961](https://mc.merill.net/message/MC1478961) (Windows, rollout September 2026); [MC1478960](https://mc.merill.net/message/MC1478960) (Mac).
