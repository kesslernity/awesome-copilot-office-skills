# GitHub Copilot and VS Code

Copy the skill folder into one of the project locations, `.github/skills/<skill>/`, `.claude/skills/<skill>/` or `.agents/skills/<skill>/`, or the personal locations `~/.copilot/skills/`, `~/.claude/skills/` or `~/.agents/skills/`. Skills work in agent mode in VS Code, the GitHub Copilot CLI, the Copilot cloud agent and other Copilot clients.

Sources, read 2026-10-24: [Use Agent Skills in VS Code](https://code.visualstudio.com/docs/copilot/customization/agent-skills), [Creating agent skills for GitHub Copilot](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/create-skills), [About agent skills](https://docs.github.com/en/enterprise-cloud@latest/copilot/concepts/agents/about-agent-skills).

These are developer tools: they cannot edit an open PowerPoint deck, so the skills return slide content as Markdown. Useful for drafting deck content next to the documents in a repository. **Unconfirmed:** live behaviour of these eight skills here.
