# Gemini CLI

Copy the skill folder to `.gemini/skills/<skill>/` or the interoperable `.agents/skills/<skill>/` in a project, or `~/.gemini/skills/` or `~/.agents/skills/` for all projects. Gemini CLI reads the name and description first and activates a skill after your approval.

Sources, read 2026-10-24: [Creating Agent Skills, Gemini CLI](https://geminicli.com/docs/cli/creating-skills/), [gemini-cli docs/cli/skills.md](https://github.com/google-gemini/gemini-cli/blob/main/docs/cli/skills.md).

Gemini CLI cannot edit an open PowerPoint deck; the skills return slide content as Markdown. **Unconfirmed:** whether Gemini in Google Workspace (Slides) accepts Agent Skills, and live behaviour of these eight skills in Gemini CLI.
